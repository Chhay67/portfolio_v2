# Developer Portfolio v2

A modern and responsive portfolio website showcasing web and mobile development skills, real-world projects, and clean UI/UX design.

This version (v2) introduces improved structure, performance, and scalability, built using the latest technologies across platforms.

## ✨ Features

- **Web Projects**: Built with  Angular, Vue.js, and Tailwind CSS,Boost Strap
- **Mobile Apps**: Developed using Flutter
- **Responsive Design**: Optimized for desktop, tablet, and mobile views
- **Case Studies**: Real-world implementations with architectural insights
- **Interactive UI**: Animations, modals, previews, and smooth navigation
- **Integration**: Linked to GitHub, LinkedIn, and downloadable resume

## 🛠 Tech Stack

- **Frontend**: Angular, Vue.js, and Tailwind CSS,Boost Strap
- **Mobile**: Flutter
- **Other**: TypeScript, Markdown, SEO meta tags
